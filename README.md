# Energy-Aware Robot Navigation
A 2D simulator for mobile robot path planning and energy-aware navigation.

## About
This project aims to simulate a mobile robot navigating through
randomly generated mazes while comparing different pathfinding
algorithms and eventually minimizing energy consumption.

## Current Features
- Random maze generation using Prim's algorithm
- Start and goal positions
- Breadth-First Search (BFS)
- A* pathfinding
- 2D visualization using Pygame
- Maze reset and regeneration
- Add a simulated robot
- Robot movement and animation
- Visualize BFS and A* paths
